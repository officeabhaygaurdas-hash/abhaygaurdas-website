# HG Abhay Gaur Das — Official Website

> **Monk, Preacher, Youth Mentor & Financial Administrator**  
> *ISKCON Sri Sri Radha Parthasarathi Mandir, New Delhi*

---

## 🌸 Overview
This repository contains the official web platform for **HG Abhay Gaur Das**, developed with modern Next.js 14 App Router, TypeScript, and Tailwind CSS. The design embodies:
- **Devotion with Discipline**: Monk-first identity, Gaudiya Vaishnava lineage, and 9 years in Vrindavan Gurukula.
- **Institutional Excellence**: Chief Financial Officer (CFO) of ISKCON Delhi, treating resources as sacred Lakshmi.
- **Youth Leadership**: Udgaar 2019 (15,000+ students, World Book of Records), Viplav conclaves, BASE hostels, and the Shreshtha CA/CS wing.
- **Pastoral Care**: Head of the Bhishma Donor Care Department, transforming fundraising into spiritual family relationships.
- **Monumental Heritage**: Project finance and coordination for the ISKCON Sri Krishna-Arjuna Temple at Kurukshetra.

## 🗂️ Site Architecture & Pages
- **`/` (Homepage)**: 11-section editorial journey (Hero, Shloka Banner, Four Pillars, Executive Monastic Overview, 6 Service Areas, Udgaar Feature, Teachings, Video Player, Gallery Mosaic, Congregational Calendar, and Connect CTA).
- **`/about`**: 14-part long-form biographical narrative and interactive timeline (1994 to present).
- **`/teachings` & `/teachings/[slug]`**: Scriptural essays with Sanskrit verses, translations, and author bio.
- **`/lectures`**: Video discourse library with topic filtering, title search, and embedded modal player.
- **`/youth`**: Youth mentorship, Udgaar 2019 World Record, BASE hostels, and Discover Yourself (DYS) curriculum.
- **`/bhishma`**: Bhishma Donor Care philosophy, home satsangs, pastoral counseling, and Vedic samskaras.
- **`/projects`**: Kurukshetra Sri Krishna-Arjuna Temple and ISKCON Delhi Glory of India Cultural Centre.
- **`/gallery`**: Archival photo gallery with category filter and full-screen lightbox modal.
- **`/events`**: Congregational calendar (Sunday discourses, youth retreats, Deepotsava satsang).
- **`/connect`**: Invitation / discourse request form with local persistence and contact details.
- **`/admin`**: Internal secretariat CMS portal with inquiry tracking, metrics, and content catalog.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start -p 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
